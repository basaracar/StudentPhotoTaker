# Student Photo Taker

## Description

A web application to take photos of students, crop them, and save them with their student ID and class name. It also provides a gallery to view the saved photos.

## Features

- Live camera preview.
- Switch between multiple cameras.
- A guide for positioning the student's face.
- Crop the photo to the specified dimensions (133x171).
- Save the photo with student ID and class name.
- A gallery to view photos by class.

## How to run the project

1.  Clone the repository.
2.  Open a terminal in the project's root directory.
3.  Run `dotnet restore` to install the dependencies.
4.  Run `dotnet run` to start the application.
5.  Open a web browser and navigate to the URL provided in the terminal (usually `http://localhost:5000` or `https://localhost:5001`).
